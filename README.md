# 中国流感监测周报 · 可视化看板

> 把每周一份 PDF 格式的《中国流感监测周报》，变成一个能滑动、能对比、能一眼看懂的数据看板。

[**🔗 在线访问**](https://lhhohbkjhaasx.github.io/cdc.html) · [**📄 数据来源**](https://www.chinacdc.cn/) · [**🏛️ 中国疾病预防控制中心**](https://www.chinacdc.cn/)

---

## 这是什么

中国疾病预防控制中心（中国国家流感中心）每周发布一期《中国流感监测周报》（PDF），内容涵盖南北方哨点医院流感样病例报告、病原学监测、暴发疫情、病毒学特征、动物禽流感疫情等。信息很全，但**一周一页、跨周对比困难**。

这个项目把周报内容提取、结构化，做成一个单文件 HTML 看板：

- 收录 2026 年第 11 周至今共 20+ 期数据
- 顶部下拉切换周次，卡片、图表、表格同步刷新
- 两张趋势图（ILI% / 阳性率）支持「最近 8 周 / 最近 12 周 / 全部」区间切换
- 纯静态、无需后端、无需构建、双击即用

### 改进
- 卡片悬停改为独立属性驱动（`translate` / `scale`），与入场动画占用的 `transform` 解耦；
  KPI 附加指针跟随的 3D 倾斜（最大 3.2°，仅 KPI，避免图表 canvas 在 3D 变换下变糊）。
- 悬停阴影改为伪元素 `opacity` 过渡，视觉不变，避免 420ms 内逐帧重绘大半径阴影。
- 切换「图表区间」只重绘图表，不再重建整页内容，KPI 数字也不会从 0 重跑。

### 修复
- 修复初次加载滚动到某些区段时卡片闪烁：入场观察器改为在区块仍完全位于视口外时触发
  （`threshold: 0` + 上下外扩 120px），并新增 `revealed` 标记，重渲染时不重播动画。
- 修复「滚动入场动画」与「悬停放大」无法同时生效：入场动画占用 `transform` 会压制 hover，
  悬停改用 `translate` / `scale`，KPI 倾斜以 `!important` 覆盖动画声明。
- 修复点击 KPI 卡片后未正确滚动到对应章节：新增统一滚动入口（`scrollPageTo` / `goToSection`）
  与 Hero 冻结机制，避免吸顶组件高度变化打断平滑滚动。
- 修复收窄「图表区间」后正文期数与选择器不一致：渲染前先校正当前期数。

### 性能
- 移除 `background-attachment: fixed`，顶部氛围渐变改用独立固定图层，消除滚动时整页背景重绘。
- 吸顶工具栏移除 `backdrop-filter`，改为高不透明度纯白底，减少滚动路径上的合成开销。
- Hero 光斑与期数触发器辉光：指针事件按 rAF 合并，并在指针进入时缓存元素尺寸，避免高频布局读取。
- 期数下拉仅在打开时计算选中项居中位置，避免关闭状态下每次渲染的强制同步布局。
- 卡片入场动画播完 1200ms 后自动摘除动画类，重渲染不再长期占用 `transform`。

### 无障碍 / 降级
- `prefers-reduced-motion`：保留阴影与描边反馈，关闭位移、缩放、倾斜与入场动画。
- `max-width: 900px`：复位触屏「粘住的 hover」状态，压缩间距与字号。
- KPI 计数在标签页隐藏或用户要求减少动效时跳过逐帧写入，直接呈现最终值。

### 说明
- 强度区间阈值取自报告内全部期数的分位值，非官方分级标准；
  自动生成的研判文案仅用于快速定位变化，不替代专业解读。

### 2026-10-17 · 第41周（总第930期）

## 🐛 修复
- **修复 Hero 收起/展开时的"弹一下"问题**：放弃 260ms 逐帧高度补间 + 逐帧滚动补偿方案，改为**瞬时切换高度 + 一次性同步补偿滚动位置**（`behavior: 'instant'` + 临时关闭 CSS 平滑滚动）。
- **移除补间期间对顶部工具栏的冻结逻辑**：删除把 `.toolbar` 临时切换为 `position: fixed` 并插入占位元素的 `freezeToolbar` / `unfreezeToolbar` 代码，工具栏不再参与补间期间的重排，彻底消除"贴在蓝色背景边缘弹一下"的抖动。

## ⚡ 优化
- **简化 `initHeroCollapse`**：去掉 `animating` 状态、`easeOutCubic` 缓动函数和逐帧 `window.scrollTo`，逻辑更轻、状态更少。
- **阈值保持分离**：收起阈值为"滚过整个 Hero"（`scrollY >= 88vh`），展开阈值为 `scrollY <= 20`，与收起后的位置（72px）拉开明显间隔，避免临界点反复切换。
- **切换不可见**：收起只发生在 Hero 完全离开视口之后，展开只发生在回到顶部时，瞬时切换对用户完全不可见，同时彻底避免与用户滚动争抢。

## 📝 说明
由于收起/展开动作本身不可见，采用**瞬时切换 + 一次性滚动补偿**比补间方案更稳定：不存在补间中途被用户滚动打断的问题，也不存在 sticky 工具栏在逐帧 `scrollTo` 期间反复重算布局的问题。

## 关于数据录入

在「快速开始」和「更新方式」之间，新增了一节 **「数据获取方式」**，讲了三件事：

1. **具体流程**：手动下载 PDF → AI读取 → 手动录入 → 保存，三步说清楚；
2. **为什么这么做**：明确表达对官方网站的尊重——不发自动化请求、不给服务器增加负载、不干扰访问策略；
3. **技术事实**：强调程序本身不访问任何网站，看板是纯静态页面。
