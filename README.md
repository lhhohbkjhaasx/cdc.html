# 中国流感监测周报 · 可视化看板

> 把每周一份 PDF 格式的《中国流感监测周报》，变成一个能滑动、能对比、能一眼看懂的数据看板。

[**🔗 在线访问**](https://lhhohbkjhaasx.github.io/cdc.html) · [**📄 数据来源**](https://www.chinacdc.cn/) · [**🏛️ 中国疾病预防控制中心**](https://www.chinacdc.cn/)

---

## 这是什么

中国疾病预防控制中心（中国国家流感中心）每周发布一期《中国流感监测周报》（PDF），内容涵盖南北方哨点医院流感样病例报告、病原学监测、暴发疫情、病毒学特征、动物禽流感疫情等。信息很全，但**一周一页、跨周对比困难**。

这个项目把周报内容提取、结构化，做成一个单文件 HTML 看板：

- 收录 2026 年第 11 周至今共 20+ 期数据
- 顶部下拉切换周次，卡片、图表、表格同步刷新
- 两张趋势图（ILI% / 阳性率）支持「最近 8 周 / 最近 12 周 / 全部」区间切换
- 纯静态、无需后端、无需构建、双击即用

## 关于数据录入

在「快速开始」和「更新方式」之间，新增了一节 **「数据获取方式」**，讲了三件事：

1. **具体流程**：手动下载 PDF → AI读取 → 手动录入 → 保存，三步说清楚；
2. **为什么这么做**：明确表达对官方网站的尊重——不发自动化请求、不给服务器增加负载、不干扰访问策略；
3. **技术事实**：强调程序本身不访问任何网站，看板是纯静态页面。
